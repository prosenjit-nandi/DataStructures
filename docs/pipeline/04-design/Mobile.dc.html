Circular Array Queue

DS-015Beginner7 min
A FIFO queue that stores elements in a fixed-size array and wraps the read and write positions around the end — so nothing is ever shifted.
What it isUse whenAvoid whenComplexityVisualCodeWalkthrough

When to use it

You know the maximum number of queued items in advance.
You need O(1) at both ends with no allocation after construction.

When not to use it

The maximum size is unknown — use a Linked Queue.
You need to insert in the middle — use a Doubly Linked List.
